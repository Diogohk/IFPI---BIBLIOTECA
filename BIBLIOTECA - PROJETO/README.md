PROJETO - SETOR BIBLIOTECA...
 Desenvolvimento de uma aplicação web voltada ao sistema da Biblioteca do IFPI - Campus Paulistana. O principal objetivo é otimizar a praticidade no registro de informações dos alunos e eliminar os conflitos na devolução de livros causados por instabilidades no sistema atual.

TECNOLOGIAS UTILIZADAS (STACK):
 - Back-end e Interface Web (Servidor, Lógica e Telas): Python com o framework Flask, utilizado para o desenvolvimento da lógica de negócios, gerenciamento de rotas e renderização do front-end;
 - Banco de Dados: MySQL (gerenciado via XAMPP), garantindo a persistência relacional dos dados de livros, usuários e empréstimos;
 - Integrações (APIs Externas): API pública do Google Books (consumida no Python com a biblioteca requests), automatizando o registro de obras através do ISBN ou título e reduzindo o esforço manual no cadastro do acervo.
